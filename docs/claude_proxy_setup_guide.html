⚙️ Antigravity IDE / VS Code Integrated Terminal
Recommended for IDE Users

Add the following block to your user settings.json. Whenever you open an integrated PowerShell terminal in Antigravity IDE or VS Code, ANTHROPIC_BASE_URL will be preset automatically.

JSON • settings.json 
{
  "terminal.integrated.env.windows": {
    "ANTHROPIC_BASE_URL": "http://127.0.0.1:8766"
  }
}
💡
Why this is ideal: Any CLI tools launched inside the IDE terminal (such as claude-code, aider, or custom agent runners) will route their calls through the proxy without needing manual environment setup each time.
⚡ Windows / PowerShell Environment Variables
Terminal & Global

Set ANTHROPIC_BASE_URL in Windows. You can set it for the current terminal session, or persist it permanently across all Windows processes for your user account.

Option A: Current PowerShell Session Only

PowerShell 
$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:8766"

Option B: Permanent User Environment Variable

PowerShell (Run Once) 
[System.Environment]::SetEnvironmentVariable('ANTHROPIC_BASE_URL', 'http://127.0.0.1:8766', 'User')

Option C: Windows Command Prompt (cmd.exe)

CMD 
set ANTHROPIC_BASE_URL=http://127.0.0.1:8766
🧩 Cline, Roo Code, & Continue Extensions
Extension Config

Popular agentic coding extensions allow specifying a custom API base URL directly in their settings.

1. Cline & Roo Code (UI Settings)

  • Open the Cline / Roo Code settings view (gear icon in the sidebar).
  • Set API Provider to Anthropic.
  • Set Base URL or Custom API URL to: http://127.0.0.1:8766.
  • Your API Key can either be entered in Cline or left blank if already saved in AI Usage Monitor's vault.

2. Continue Extension (config.yaml)

YAML • ~/.continue/config.yaml 
models:
  - name: Claude 3.7 Sonnet (Proxied)
    provider: anthropic
    model: claude-3-7-sonnet-20250219
    apiBase: "http://127.0.0.1:8766"
🐍 Python & Node.js / TypeScript SDKs
Programmatic

If you are developing custom agent pipelines or automation scripts using the official Anthropic client libraries, specify base_url on initialization.

Python (anthropic SDK)

Python 
import anthropic

client = anthropic.Anthropic(
    base_url="http://127.0.0.1:8766"
    # api_key is optional if stored in AI Usage Monitor's DPAPI Vault!
)

response = client.messages.create(
    model="claude-3-7-sonnet-20250219",
    max_tokens=1000,
    messages=[{"role": "user", "content": "Hello via transparent proxy!"}]
)
print(response.content[0].text)

Node.js / TypeScript (@anthropic-ai/sdk)

TypeScript 
import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic({
  baseURL: 'http://127.0.0.1:8766',
});

const msg = await anthropic.messages.create({
  model: 'claude-3-7-sonnet-20250219',
  max_tokens: 1000,
  messages: [{ role: 'user', content: 'Hello via transparent proxy!' }],
});
console.log(msg.content[0]);
📁 Zero-Configuration Local Scanner (Claude Code CLI)
Built-in Fallback

If you are using the official Claude Code CLI (claude command), AI Usage Monitor includes an automated background log parser that scans your local logs without requiring any proxy redirection.

✨
How it works: Claude Code persists full session traces as JSONL logs in ~/.claude/projects/ and ~/.claude/sessions/. AI Usage Monitor's scan_local_logs() automatically parses these logs, extracts model names, input/output tokens, and prompt cache hit counts, and reconciles them into your SQLite database idempotently.

Trigger Manual Scanner Ingestion:

You can trigger an on-demand scan via the Web Dashboard, or programmatically via the REST API:

PowerShell 
Invoke-RestMethod -Uri "http://127.0.0.1:8765/api/providers/claude/scan" -Method Post
