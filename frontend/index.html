Configure Claude (Anthropic)

Procure Key Need an Anthropic API Key?

Keys are managed in the Anthropic Console. You can generate a new secret key for direct API calls or the CLI proxy in seconds.

1 Click Open Anthropic Console below.
2 Navigate to API Keys and click "Create Key".
3 Copy the key and paste it into the field below.
🚀 Open Anthropic Console ↗ 📊 Usage & Billing ↗ 📚 API Quickstart ↗

🔒 Encrypted immediately via Windows DPAPI (crypt32.dll). Tied directly to your Windows login; never stored in plaintext.

Configure Google Gemini

Procure Key Need a Google Gemini API Key?

Google AI Studio provides free and pay-as-you-go API keys with instant activation for Gemini 1.5 Pro, Flash, and 2.0.

1 Click Open Google AI Studio below.
2 Sign in with your Google account and click "Create API key".
3 Copy the key and paste it into the field below.
