📘 LAN Discovery & Subnet Configuration Guidance
Subnet Masks Explained:
  • /24: Sweeps 254 host IPs (e.g. 10.1.7.1 - 10.1.7.254). Fast (~2-4s). Recommended for standard home & lab subnets.
  • /28: Sweeps 14 hosts. Ultra-fast for small clusters.
  • /16: Represents 65,534 hosts. Full /16 sweeps are clamped automatically. Use specific ranges like 10.1.7.1-10.1.7.100 to avoid network congestion!
Remote Machine Binding (Firewall & Host):
  • Ollama: By default listens ONLY on localhost. On remote PCs (e.g. ASUS ROG / Jamese-PC), set Windows environment variable OLLAMA_HOST=0.0.0.0 and allow inbound TCP port 11434 in Windows Firewall.
  • LM Studio: In Developer tab, check "Serve on Local Network (0.0.0.0)".
  • Aliases: Devices are indexed by hostname alias (e.g. Jamese-PC) so dynamic DHCP IP address changes don't lose history!

1. Configure External Applications as an Ollama Instance Drop-in Replacement

Any platform, web UI (e.g. Open-WebUI), dev tool (Continue.dev, Cursor), or application can connect to this bridge as if it were a native Ollama instance. AI Usage Monitor intercepts all requests, meters token usage, enforces client burst quotas, and dispatches to local or LAN worker nodes.

Environment Variable (Bash / Zsh / Linux): 
export OLLAMA_BASE_URL="http://127.0.0.1:8989"
Environment Variable (Windows PowerShell): 
$env:OLLAMA_BASE_URL='http://127.0.0.1:8989'
Python ollama Official Library: 
import ollama

client = ollama.Client(host='http://127.0.0.1:8989')
response = client.chat(model='llama3:latest', messages=[
    {'role': 'user', 'content': 'Hello! Synthesize status.'}
])
print(response['message']['content'])

3. Model Context Protocol (MCP) Server JSON-RPC 2.0

Autonomous agents and platforms can directly query available tools, trigger multi-node prompt executions, scan LAN devices, and manage client limits programmatically over JSON-RPC 2.0 at http://127.0.0.1:8765/api/mcp/rpc.

List Available Tools (cURL): 
curl -X POST http://127.0.0.1:8765/api/mcp/rpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "id": 1, "method": "tools/list", "params": {}}'
Dispatch Prompt Across Compute Pool via Tool Call: 
curl -X POST http://127.0.0.1:8765/api/mcp/rpc \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "id": 2, "method": "tools/call", "params": {"name": "prompt_cluster", "arguments": {"model": "llama3:latest", "prompt": "Analyze data."}}}'
